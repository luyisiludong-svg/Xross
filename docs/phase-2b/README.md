# Phase 2b (Beta) — customization engine (Theme 2.0)

Phase 2b turns the launcher's look into data: a profile HUD and game tiles (2b.1), then Theme 2.0,
one declarative pack format (`theme.json` v2) that can express a vanilla XMB, a Y2K look, OLED
True Black or E-Ink, with every value user-overridable. Theme 2.0 is complete as of 2026-11-15:
2b.1–2b.5, 2b.7 and 2b.8 are merged into `main`, 2b.6 (haptics) is iced and 2b.9 (Web Theme
Studio) has not started. The plan and the remaining milestones are in
[Roadmap §4.3](../../Roadmap.md#43-phase-2b--customization-engine-theme-20); the pack format as
built is in [`THEME_SPECIFICATION.md`](../THEME_SPECIFICATION.md).

Each slice has its own folder. `PROMPTS.md` is the implementation plan, split into slices with
their scope, tests and device checks (and, from 2b.5 on, as-built notes); `STATUS.md` is the
evidence: unit tests, device suites, frame timing and what was not verified.
